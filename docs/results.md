# kv_c：已有数据总结

2026-10-12。本页汇总支持主方法的全部已有证据，以及各候选的淘汰依据。构造与数学见 [method.md](method.md)。全部质量证据为约 188 万参数字符模型；无 GPU、无大模型质量；验证集已参与探索，选择均公开记录。

## 实验口径

TinyShakespeare（SHA256 `86c4e6aa9db7c042ec79f339dcb96d42b0075e16b8fc2e86bf0ca57e2dc565ed`），连续 90/10 划分。每个构造从头 1600 步、B=16、n=256，每种子 6,553,600 个目标字符；种子 0/1/2 配对私有/公共初始随机张量、样本顺序与优化配置；AdamW 3e−4、betas=(.9,.95)、wd=.1、30 步 warmup、cosine 到 .1 倍、clip=1；取最终一步，不选 checkpoint。全验证 111,539 个目标在每个评分长度恰好计一次，固定 chunk 重置上下文；512/1024 为长度外推。原始记录：[clean_full_comparison.json](../outputs/clean_full_comparison.json)。

## 剂量-效应：时间算子为何被放弃

时间算子指旧前缀构造中每层提交时按 λ 混合全局因果均值的机制（committed = (1−λ)·新值 + λ·前缀均值）；λ=0 即主方法。全局时间混合量 λ 从大到小，三个独立点、两个宽度，方向完全一致：

| 家族 | λ（每坐标总量） | 256 | 1024 |
|---|---|---:|---:|
| w16 只过滤新增量 | 1/4 | 1.528197（最佳） | 1.940507（近最差） |
| w16 局部前缀 | 1/8 | 1.531904 | 1.886890 |
| w16 无传输 | 0 | 1.548394 | 1.747392（最佳） |
| w24 局部前缀 | 1/12 | 1.530893 | 1.807447 |
| w24 无传输 | 0 | 1.545150 | 1.745639（最佳） |

**混合越多，训练长度内越好、外推越差，严格单调。** 结构性解释：全局因果均值的统计量随 n 漂移（训练时均值至多 256 项，评测 1024 项），模型按训练长度校准 λ，4 倍长度即失配。512 列居间、方向混合，与"漂移随长度加剧"一致。这个税是全局均值的内生属性，修不好；要保留平滑只能用统计量平稳的 EMA/短窗口（未测，列为开放消融）。

训练长度内的代价是一致为正的：w24 无传输 − 前缀 = +0.014257（三种子同号，95% 区间跨零）；w16 = +0.016490（区间 [+0.0038, +0.0292] 不含零）。这是无传输唯一已知的质量代价。

## 精度与独立核对（前缀臂既有记录）

- 独立全宽源递推 oracle 共 60 配置：多 KV 头、完整/循环边界、FP64 梯度、非平凡 RMS γ、因果性、不可变历史、reset/replay、两种 tile 与 prefill。
- 三种训练权重流式：FP32 最大 logits 误差 1.597e−05；BF16 0.00758；BF16 平均 KL ≤ 4.67e−08。全验证 BF16 相对 FP32 最大 |ΔNLL| = 3.64e−04。
- native C++ 完整私有计算 18 例（3 种子×3 上下文×2 精度）：相对 torch 参考最大 logits 误差约 6.5e−06；紧凑历史实测为物化 KV 的 45.3125%（context 1024：478,848 对 1,056,768 字节）。
- native 核对仅验证函数等价（repeats=0），**没有计时数据**；没有任何 GPU 测量。

## 淘汰项一览

| 候选 | 死因 |
|---|---|
| 局部/全宽锚点 | 质量无一致优势，多出块长、锚点角色与摘要规则 |
| 局部前缀（时间混合） | 训练长度内小优（+0.014~0.016 NLL），外推显著差（−0.06~−0.14）；降为 135M 配对对照臂 |
| 只过滤新增量 λ=1/4 | 256 全表最佳但 1024 崩盘（1.940507）；时间混合剂量上限的直接证据 |
| 固定范围无传输 | 400 步优势未延续：1024 = 1.839606 对循环 1.747392；深层刷新不足 |
| 零发布全层共享 | 400 步三种子一致差（128 长度 ΔNLL=+0.114）；未补全训 |
| 全宽幂等/原全宽主线 | 读取需重放/恢复状态；被写入范围闭合取代 |
